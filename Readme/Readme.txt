# Employee Role Management System

## 📌 Project Overview

The **Employee Role Management System** is a SQL-based database project developed using MySQL. It is designed to manage employee information, departments, job roles, and salary details in an organized and efficient way.

This project demonstrates how relational databases can be used to store, manage, retrieve, and analyze employee-related information using SQL queries.

## 🎯 Project Objectives

- Store and manage employee details.
- Maintain department and role information.
- Track employee salary details and salary history.
- Retrieve employee information using SQL queries.
- Generate meaningful reports using joins and views.
- Maintain data accuracy using constraints and triggers.
- Understand database operations and transaction management.

## 🛠️ Technologies Used

- **Database:** MySQL
- **IDE:** MySQL Workbench
- **Language:** SQL
- **Documentation:** Markdown

## 🗂️ Database Structure

The project consists of four main tables:

| Table Name | Description |
|---|---|
| departments | Stores department details |
| roles | Stores employee job roles |
| employees | Stores employee information |
| salary_history | Maintains employee salary changes |

## 🚀 How to Run the Project

1. Install MySQL Server and MySQL Workbench.
2. Open MySQL Workbench.
3. Create a new SQL query tab.
4. Open the project SQL script.
5. Execute the database creation and table creation scripts in the correct order.
6. Insert the sample records.
7. Execute the SQL queries to explore the project features.
